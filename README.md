# Telegram-бот для Google Календаря

Напишите боту «вторник 17:00 встреча с Максимом два часа». Он покажет, как понял сообщение, и после нажатия «Добавить» создаст событие в вашем Google Календаре.

## Что понимает

- `завтра 17 встреча с Максимом два часа`
- `вторник 17:00 встреча с Максимом`
- `25.11.2026 15:30 врач на 30 минут`
- `17 тренировка` — ближайшие 17:00 сегодня или завтра.

Поддерживаются сегодня, завтра, послезавтра, дни недели и даты в формате ДД.ММ или ДД.ММ.ГГГГ; время — `17` или `17:30`. Ближайший одноимённый день недели считается следующим, если сегодня он уже наступил. Без продолжительности — один час; можно указать «два часа», «90 минут» или «полчаса». Если в названии есть числа, переформулируйте его без чисел. Поддерживаются описанные форматы, а не произвольный разговорный текст. Время берётся из `TIMEZONE`; по умолчанию Москва. Кнопки действуют до перезапуска бота, только для последнего отправленного события.

## Перед запуском

Нужны компьютер или сервер с Python 3.10+ и доступом к интернету. GitHub хранит код, но не запускает бота постоянно. Пока бот не запущен, он не отвечает.

1. В Telegram создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`. Сохраните выданный токен в секрете.
2. Узнайте свой **числовой Telegram user ID**, например через [@userinfobot](https://t.me/userinfobot). Впишите именно свой ID: бот будет отвечать только этому пользователю в личном чате. Не используйте имя пользователя вместо ID.
3. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **Google Calendar API**, настройте OAuth consent screen и, если приложение находится в режиме Testing, добавьте свой Google-аккаунт в тестовые пользователи. Создайте OAuth client типа **Desktop app** и скачайте JSON как `credentials.json` в папку проекта. Подробности: [инструкция Google](https://developers.google.com/workspace/calendar/api/quickstart/python).
4. Скопируйте `.env.example` в `.env`. Заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_USER_ID`; при необходимости измените `TIMEZONE`. `GOOGLE_CALENDAR_ID=primary` означает основной календарь аккаунта, в который вы войдёте.
5. В терминале в папке проекта выполните:

```bash
python -m venv .venv
# macOS / Linux:
source .venv/bin/activate
# Windows вместо предыдущей строки: .venv\Scripts\activate
pip install -r requirements.txt
python authorize.py
python bot.py
```

При первом запуске `authorize.py` откроется браузер: войдите в нужный Google-аккаунт и разрешите управление событиями. Создастся `token.json`. Если бот будет работать на сервере без браузера, сначала выполните авторизацию на личном компьютере, затем безопасно перенесите `token.json` и настройки на сервер. Перезапускайте бота после изменения `.env`. Напишите ему `/start`.

**Секреты:** `.env`, `credentials.json` и `token.json` не загружайте на GitHub и не пересылайте в чат. Они указаны в `.gitignore`. Если токен бота был опубликован, отзовите его через BotFather и создайте новый. Google-токены также нужно отозвать при утечке. Не запускайте одновременно несколько экземпляров с одним токеном.

Тесты разбора сообщений: `python -m unittest discover -s tests`.
